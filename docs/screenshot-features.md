# 手机截图对应功能（小米耳机 1.38.0）

参考用户提供的 5 张截图和小米耳机 1.38.0 APK。以下记录桌面版本 0.1.7 的实现范围；“已接入”表示已有对应协议和界面实现，有回读能力的设置会检查回读，不表示所有功能已逐项实测。原截图及 APK 不随公开项目分发。

| 手机功能 | 桌面 0.1.7 | 对应协议 / 证据 |
| --- | --- | --- |
| 左右耳电量、充电状态 | 已接入；额外显示充电盒，未知时显示 — | 设备信息 0x07 / 状态通知 0x00 |
| 通透 / 降噪 / 关闭 | 已接入，有应答及运行状态回读 | ANC 0x08，02-04-mode；运行字段 0x09 |
| 自适应降噪 | 已接入 | 配置 0x25 |
| 手动降噪强度 | 连续滑块，从轻到深；开启自适应后禁用 | 配置 0x0B，目标 0x01，内部值 0–19；官方 o76cn 配置与 APK |
| 通透强度 | 三位置滑块：通透 / 人声增强 / 环境增强 | 配置 0x0B，目标 0x02，值 0/1/2；截图、APK、官方 o76cn 配置 |
| 个性化降噪 | 已接入 | 配置 0x3B；读取 01 与截图开启状态一致，写入仍需实机验证 |
| 单击 / 双击 / 三击 | 已接入左右耳分别设置 | 配置 0x02，手势类型 04 / 01 / 02 |
| 长按 | 已接入动作与噪声循环 | 手势类型 03 / 循环配置 0x0A |
| 滑动左右耳 | 已读取音量加减配置，支持按该值写入，保留未知当前值 | 实机手势类型 05、动作 0B 对应截图“音量加减”；其他滑动选项尚未看到，不提供猜测的动作 |
| 自适应听感 | 已接入 | 配置 0x29；读取 01 与截图开启状态一致 |
| 音效模式 | 已接入标准、低音增强、高音增强、人声增强、自定义 | 配置 0x07；06 与截图高音增强对应；完整手机预设列表待补充 |
| 自定义均衡器 | 已接入 10 段、−6 至 +6 dB，保存并启用 | 配置 0x37；使用耳机返回的频率，避免参考实现将 2000 Hz 写为 2016 Hz |
| 佩戴检测 | 已接入，写入后读取运行状态确认 | 写命令 0x08，`02-06-value`，0 开启、1 关闭；读运行命令 0x09 的字段 0x0A；0x7E 只接收配置推送 |
| 双设备连接 | 已接入 | 配置 0x04；切换可能影响手机的现有连接 |
| 自动接听电话 | 已接入耳机开关 | 配置 0x03；Windows 是否能自动接听具体通话软件不在已验证范围内 |
| 查找耳机 | 已接入左右耳 / 双耳、停止、10 秒停止流程；未进行真实响铃 | 配置 0x09 的参考指令，当前固件支持仍待验证 |
| 空间音频 | 已接入主开关与头部追踪，新增设置未实机验证 | 官方 APK：写配置 0x1D、读配置 0x1E；机型功能 2002 / 2004 |
| 空间音频场景 | 已接入经典 / 音乐 / 视频 / 游戏 / 有声书 | 官方 APK：配置 0x36；机型功能 2009 提供场景 1–5 |
| 耳塞贴合度检测 | 已接入就绪后播放、左右耳结果、取消和 10 秒超时；新版检测效果待实机确认 | 启停配置 0x05；F4 结果配置 0x06，3 就绪、1 良好、2 调整；用户需本地准备官方音频 |
| 设备重命名 | 尚未接入 | 手机展示昵称与耳机返回的蓝牙名不同，需确认昵称存储位置与真实修改方式 |
| 固件更新 | 尚未接入 | 需单独理解包格式、传输和恢复流程 |
| 删除设备 | 使用“打开 Windows 蓝牙设置”入口 | 由用户在 Windows 中取消配对；应用不自动删除配对 |

## 尚缺的页面或材料

- 空间音频子页面可进一步核对布局与文字；主开关、追踪及场景已根据 APK 和机型配置接入。
- 音效模式的完整列表、自定义 EQ 页面。
- 长按和滑动的选项页面。
- 贴合度检测、查找耳机的操作与结果页面。
- 已取得用户提供的官方应用 com.mi.earphone 1.38.0 APK，并定位强度设置逻辑；其他功能继续以 APK、机型配置及实机证据核对。

## 桌面新增

托盘模式、托盘噪声切换、系统深浅主题图标、关闭方式选择、可选自动重连、可选开机启动、记住已选设备，以及未知电量 / 未知手势值的保留与显示。
