# Mi Buds Control 0.1.7

这是面向 Windows 11 和 REDMI Buds 6 Pro 国行耳机的第三方控制应用，当前适配固件 1.1.9.9。使用 C#、WPF、Windows 原生蓝牙 API 与系统 .NET Framework，无需安装 Python、手机模拟器或额外蓝牙驱动。

本版延续基于原始 0.1.4 的关闭处理、贴合度结果接收和左下角署名调整，并修复 0.1.6 初始化读取导致连接失败的问题。原版界面样式与托盘图标沿用 0.1.4。公开包不含官方检测音频，贴合度检查需按 [音频准备说明](fit-audio.md) 从自己的 APK 提取；其他功能不需要该音频。

## 使用

1. 在 Windows 蓝牙设置中配对并连接耳机，保持耳机开启。
2. 若手机正在使用“小米耳机”应用，先退出该应用，给电脑控制连接留出空间。
3. 双击 `MiBudsControl.exe`。程序会查找已配对的 Buds 耳机并尝试连接。
4. 选择降噪、通透或关闭；其他页面可设置手势、音效、均衡器和常用开关。
5. 点击窗口关闭按钮时，默认弹出“完全退出 / 缩小到托盘 / 取消”的选择。右键托盘图标可以切换模式或直接“完全退出应用”。

自动重连默认开启，开机启动默认关闭。多副耳机时请在顶部选择目标设备，然后点击“连接耳机”或“重新连接”。

从旧版升级：右键旧版系统托盘图标 →“退出”或“完全退出应用”，再运行新版解压文件夹中的 `MiBudsControl.exe`。已有设备和重连偏好继续使用，关闭询问默认开启；若此前设置过开机启动，请在新版中关闭后重新开启，以更新启动路径。

## 关闭与完全退出

- **完全退出：**停止检测音频、结束耳机控制连接、移除托盘图标并结束应用进程。蓝牙清理最多等待 5 秒，避免因设备无响应而一直无法退出。
- **缩小到托盘：**隐藏主窗口，保留托盘和自动重连；正在进行的贴合度检查会取消并停止检测音频。双击托盘图标可重新打开窗口。
- **取消：**继续使用当前窗口，不中断正在进行的检查。按 Esc 或关闭选择框也相当于取消。

可在“更多设置”关闭“关闭窗口时询问退出方式”。此后开启“不询问时缩小到托盘”会隐藏窗口，关闭该选项会完全退出。托盘菜单中的“完全退出应用”始终直接退出。

## 托盘图标与系统主题

托盘使用提供的耳机图标：Windows 系统主题为浅色时显示黑色线条，深色时显示白色线条。启动时读取系统主题，并监听主题变化；每秒自动检查一次，以补充可能遗漏的系统通知。切换 Windows 主题无需重启程序。

依据的是 Windows“默认 Windows 模式”／系统任务栏主题，即 `SystemUsesLightTheme`；单独改变“默认应用模式”不会改变托盘图标。图标已内嵌于 EXE，不需要访问原始截图目录。

## 佩戴检测与耳机贴合度检查

在“更多设置”中：

1. “佩戴检测”修改耳机端的自动播放／暂停开关，并读取实时状态确认。具体播放器需要支持耳机的播放控制。
2. 佩戴好双耳，暂停其他音频，保持环境安静。
3. 在“耳机贴合度检查”中确认检测音频输出是 REDMI Buds 6 Pro；没有输出时点击“刷新音频输出”，并确认耳机的音频连接可用。
4. 点击“开始检查”。程序发送官方启用命令，收到耳机就绪通知后播放检测音频，接收左右耳结果。检测超时为 10 秒，左右耳分别显示“贴合良好”或“需要调整”。
5. 可随时“取消检查”；完成、超时、断线、缩小到托盘或完全退出时停止音频。关闭选择框中点“取消”会继续检查。检查期间其他耳机设置暂时禁用。
6. 提示调整时，改变佩戴位置或换合适尺寸的耳塞后重新检查；未返回结果时只显示错误，不推测贴合程度。

请保持 `fitness_detect.wav` 和 EXE 在同一个文件夹。下载包附带 `tools/extract-fit-audio.ps1` 和 [音频准备说明](fit-audio.md)，需要用户从自己的小米耳机 1.38.0 APK 准备音频。程序不会改变系统音量；该官方资源不属于项目代码的 AGPL 授权范围。

## 空间音频

在“音效设置”的“空间音频”卡片中：

1. 打开“开启空间音频”。程序等待耳机成功应答，并读取真实状态。
2. 开启后可设置“头部追踪”；关闭追踪时保留空间音频。
3. “场景渲染”可选择经典、音乐、视频、游戏、有声书。选择后回读确认。
4. 关闭空间音频后，头部追踪与场景选择禁用，追踪偏好保留在耳机中。

可播放熟悉的音乐或视频试听。这些控件设置耳机端的效果；Windows 空间音效在系统声音设置中单独调整。未取得状态时，控件保持禁用，不显示虚构的默认开关值；可点击“刷新状态”或重连。

## 强度调节

- 切到“降噪”，关闭“自适应降噪”，即可拖动从“轻”到“深”的连续滑块。官方机型配置使用 20 个内部值（0–19），界面不再使用轻度 / 均衡 / 深度三个选项。
- 切到“通透”，使用三个位置：通透、人声增强、环境增强。其协议值依次是 0、1、2。
- 松手后稍候，程序写入并回读确认；键盘或点击调整会合并短时间内的操作。拖动中不写入，避免连续请求堆积。
- 开启自适应降噪后，手动滑块禁用。切换到其他模式后，相应强度控件隐藏。
- 未取得当前强度或设备型号不匹配时，不发送强度设置。

## 当前功能

- 左耳、右耳和充电盒电量；未收到电量时显示 `—`。
- 降噪 / 通透 / 关闭、自适应降噪、个性化降噪，以及手动强度。
- 左右耳单击、双击、三击、长按、滑动，以及长按噪声模式循环。
- 自适应听感、音效预设、10 段自定义均衡器。
- 空间音频开关、头部追踪与五种场景渲染。
- 佩戴检测、双设备连接、自动接听电话的耳机端开关。
- 耳机贴合度检查，含检测音频、左右耳结果、取消与超时。
- 查找双耳 / 左耳 / 右耳、手动停止与 10 秒停止流程。使用前先摘下耳机。
- 系统托盘、自动重连、记住目标设备、可选开机启动。

设置写入会检查耳机应答；可读取的设置会回读确认。失败时显示错误，控件恢复为实际读取值。未知手势值保留为“保留当前设置”。新连接前不自动套用预设。

## 当前限制

0.1.6 根据官方 APK 修正了贴合度结果通知编号，既有实机日志确认耳机会发送 `0x06` 就绪与左右耳结果。0.1.7 根据失败日志修正初始化配置查询。此前连接、认证与配置读取已实测；本轮只编译和静态审阅，未运行新版实机连接、贴合度测量或播放检测音频。实际连接、检测效果和空间音频听感仍需使用新版确认。

设备重命名和固件升级尚未接入。取消配对请使用“打开 Windows 蓝牙设置”。耳机端“自动接听电话”开关不保证控制所有 Windows 通话软件。当前机型配置未提供其他机型的个性化空间音频校准或空间音频算法选择，因此不展示这些选项。

## 连接问题

0.1.6 会在认证成功后读取一项没有响应的配置，随后超时并断开。遇到这次问题请先从托盘完全退出 0.1.6，再启动 0.1.7。新版已移除该主动查询，保留通过运行状态读取佩戴开关；非必需配置超时不再使初始化失败，实际断线时停止后续读取。

若提示“耳机控制连接暂时不可用”，请确认耳机已经开机并连接此电脑，退出手机耳机应用；仍失败时可在 Windows 中断开并重新连接耳机，再点击“重新连接”。音频已连接与控制连接可用是两项不同状态。

本地日志和设置位于 `%LOCALAPPDATA%\MiBudsControl`。日志含协议帧和设备地址，反馈问题时可以提供该文件夹中的 `bluetooth.log`；公开分享前隐去设备地址和其他个人信息。
